# FreeNote（Android 版）

FreeNote 的安卓端：与 Windows 版（`../windows`）相同的便签功能与数据格式，
支持两种同步方式——**局域网 P2P 直连**（无需服务器）与 **FreeNote 服务端中转**（可跨网络）。
两种协议都与 Windows 版完全互通，可以同时开启。

> 目录结构：`freenote/android`（本安卓端）、`freenote/windows`（Windows 端）、
> `freenote/server`（同步服务端）。

## 与 Windows 版的互通方式

| | FreeNote（Android） | FreeNote（Windows） |
| --- | --- | --- |
| P2P 同步 | 同一协议（App 前台运行时监听） | 内置 HTTP 同步服务 + UDP 组播发现 |
| 服务器同步 | 连接 FreeNote 服务端（`../server`） | 同一协议、同一账号 |
| 认证 | P2P：相同的同步账户 + 相同的「同步口令」；服务器：用户名 + 密码 | 同 |
| 数据格式 | 两端完全一致（Room `notes` 表、JSON 备份、锁定便签加密算法、图片内容寻址命名） | — |

## 功能

- 便签：标题、正文、8 种颜色、置顶、标签、回收站（30 天自动清除）
- 文件夹：嵌套文件夹管理（新建/重命名/删除），便签归属单个文件夹并随同步传播
- Markdown 预览（含**管道表格**渲染）、清单（Checklist）模式、字数统计、
  模板（会议记录/任务清单/日记/每周总结）、`[[便签标题]]` 双向链接（预览中点击跳转同名便签）
- 正文内联图片：内容寻址的便携标记 `![](freenote-img:<sha256前16位>.<扩展名>)`，
  **图片随 P2P/服务器同步与 JSON 备份一起迁移**（协议 v6）；旧版 `file://` 引用启动时自动迁移
- 单条便签分享与导出：系统分享（文本）、导出为 Markdown 文件（SAF）
- 系统分享接收：其他 App「分享文本到 FreeNote」直接进入新建便签并预填
- 多选批量操作：长按卡片进入多选，批量移到回收站、移动文件夹、添加标签、全选
- 快速记录：长按应用图标的「新建便签」快捷方式、快捷设置面板「快速记录」磁贴、
  桌面小组件（默认显示最近 4 条；长按小组件可**固定展示任意一条便签**）
- 提醒通知（支持重复提醒：每天/每周/每月，到点自动排下一次）、应用锁 PIN
  （AES-256-GCM + PBKDF2，与 Windows 版算法一致）
- 搜索（**解锁会话内可搜索锁定便签的加密内容**）/ 标签筛选 / 排序（升/降序）/
  时间线视图（按修改日期分组：今天/昨天/…）
- 历史版本：每次修改自动留存旧版本（同内容/5 分钟合并，最多 30 版，仅本机），
  编辑器「历史版本…」可预览并恢复，恢复前自动留存当前状态
- 导入：JSON 备份、`.md`/`.txt` 文件（每个文件一条便签，首个 `#` 标题作便签标题）、
  Evernote `.enex` 导出（按内部便签展开；附件不入库，正文以占位文字标记）
- 自动备份：每 24 小时（应用启动时检查）把全量 JSON（含图片）写入所选 SAF 文件夹
  （长按文件夹授权，重启后仍有效）；可配置 WebDAV 地址在备份后自动上传；支持「立即备份一次」
- **P2P 同步**：局域网自动发现、增量交换、最后写入者获胜（LWW）、删除墓碑传播、
  摘要快速通道（含图片状态）、账户隔离、HMAC 签名认证与防重放
- **服务器同步**：登录 FreeNote 服务端（与 Windows 版同一账号）跨网络同步；
  服务端只保存密文，锁定便签的正文/标题对服务器不可见；
  支持修改密码（其他设备令牌一并失效）、注销账号（删除服务端数据，本机数据保留）

## 安装与运行

1. 用 Android Studio 打开 `freenote/android`，或命令行构建：
   ```powershell
   cd freenote/android
   .\gradlew.bat assembleDebug
   ```
2. 安装 `app/build/outputs/apk/debug/app-debug.apk` 到手机（Android 8.0+）。

## 数据位置

- 便签库：应用私有 `databases/freenote_database`（Room，表结构与 Windows `notes.db` 一致）；
- 图片附件：应用私有 `files/note_images/`（内容寻址命名 `<sha256前16位>.<扩展名>`）；
- 设置：应用私有 SharedPreferences（含 PIN 哈希、同步账户、WebDAV 凭据等）；
- 同步口令与服务器令牌用 Android Keystore 加密存储（随应用卸载销毁）。

## 两分钟配对（P2P，Android ↔ Windows）

1. 两端启动 FreeNote；
2. **两端登录同一服务器账号**（「设置 → 同步 → 服务器同步」），或都不登录服务器、
   在「设置 → 同步 → 离线账户」填写**完全相同**的账户名（推荐在一端点「生成 UUID」后复制粘贴，无需联网注册）；
3. 两端填写**完全相同**的同步口令（一端点「生成随机口令」后复制）；
4. 两端勾选「启用 P2P 同步」（网络功能默认关闭，需显式开启）；
5. 局域网内几秒内即可互相发现，保存便签后自动同步。

> P2P 协议当前为 v6（账户隔离 + 正文加密 + 同毫秒内容哈希仲裁 + 附件内容寻址同步 +
> 重复提醒字段）。两端协议版本不一致时无法互通，**升级需三端同时更新**。

## 服务器同步（跨网络）

1. 在任意一台常开设备上部署 FreeNote 服务端（见 `../server/README.md`）；
2. 在「设置 → 同步」填写服务器地址并用**同一个账号**登录（没有账号先注册）；
3. 登录后自动同步一次；之后按设定间隔自动同步，也可在同步设置里手动「立即同步」。

## P2P 协议要点（与 Windows 版完全一致）

1. **账户 + 口令**派生组密钥（PBKDF2-HMAC-SHA256），正文 AES-256-GCM 加密，
   请求附时间戳 + 随机数 + HMAC-SHA256 签名（防重放、防篡改）；
2. **发现**：UDP 组播 `239.255.42.42:8766`（仅 App 前台运行时参与）；
3. **两步交换**：`manifest`（状态清单 + 摘要 + 附件名清单）→ `exchange`（互通增量，LWW 合并）；
4. **附件补传**（协议 v6）：`image_put` 推送对方缺失的图片、`image_get` 拉取本机缺失的图片，
   每批 ≤8 张 / ≤8MB，按内容哈希校验；
5. **摘要去重**：`id:updatedAt:isDeleted:内容哈希` + 附件引用状态（`name:本机是否有`），
   「便签一致但图片缺失」的设备也会被发现并触发补传。

## 安全说明

- 传输加密与签名同 Windows 版：账户/口令不一致的设备互相不可见、无法解密或伪造报文；
- 同步口令与服务器令牌用 Android Keystore 加密存储；
- 锁定便签只加密标题与正文，**标签/文件夹/颜色等元数据仍为明文**（跨端筛选需要明文索引）；
- 本机数据库中普通便签为明文，请依赖系统磁盘加密与设备锁屏保护数据；
- 普通便签的 JSON 备份为明文（锁定便签仍为密文）；自动备份与 WebDAV 上的文件请按敏感数据保管；
- 服务器同步默认为明文 HTTP（自建服务器），公网部署请按 `../server/README.md` 配置 HTTPS。

## 与 Windows 版的互通

- P2P 与服务器协议与 Windows 版字节级一致；`SyncProtocolTest` 使用 Python 生成的
  密钥/签名向量做跨语言校验；
- 双方的 JSON 备份可以互相导入（格式 v6 起包含图片附件）；
- 图片附件使用相同的内容寻址命名，跨端按哈希去重与校验；
- `notes.db` 副本可被 Windows 版直接打开（表结构一致）。

## 限制

- P2P 监听与自动同步仅在 App 前台运行时工作（息屏/切后台即停止），
  需要接收同步时请保持 App 打开；服务器自动同步在回到前台后触发；
- 历史版本仅存本机、不参与同步（恢复会产生一次普通修改并随同步传播）；
- 自动备份在应用启动时检查是否到点（每 24 小时一次），应用长期未打开期间不会执行；
- 协议 v6 起附件参与同步，升级需三端同时更新；
- 小组件固定便签后，若该便签被删除，小组件自动回退显示最近 4 条。
